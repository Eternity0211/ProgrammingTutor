## RAG 与幻觉控制

关键词 RAG 在 6 个问题 × 3 轮中自动通过 15/18：有证据问题 grounded 率和引用覆盖率均为 100%。普通无证据问题能正确拒答。提示注入场景的回答文本三轮都明确拒绝编造，但引擎状态仍被标记为 `grounded`，因此自动“正确拒答率”为 50%。这说明回答内容的安全性较好，但状态分类仍有改进空间；该项已进入人工复核。

## 可靠性发现

当前严格 schema 校验能显式暴露坏输出：Code Review 有 3/36 次不可用，Emotion 与 Navigation 各有 1/36 次降级。旧版表面可用率更高，但会把部分 JSON 解析失败吞掉并返回默认对象，不能直接等同于真实质量更高。建议后续增加 JSON 修复/重试，再以相同数据集回归。

依赖安全审计在两版同一时点均为 140 个报告项（28 low、73 moderate、33 high、6 critical），没有改善，也没有因本次改造新增差异。这是独立的后续治理项。

## 待人工确认

盲评文件包含 12 组随机打乱的 Agent A/B 输出和 6 个 RAG 样本。人工标注后可得到 Code Review 正确率、情绪识别质量、导航命中、无依据断言和总体胜率；这些指标尚未填入，因此本报告不虚构最终教学收益或学生真实修复率。
