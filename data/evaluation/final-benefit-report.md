- 基线：用户确认的分支起点 `688863a`。

## RAG 与幻觉控制

关键词 RAG 在 6 个问题 × 3 轮中自动通过 15/18：有证据问题 grounded 率和引用覆盖率均为 100%。普通无证据问题能正确拒答。提示注入场景的回答文本三轮都明确拒绝编造，但引擎状态仍被标记为 `grounded`，因此自动“正确拒答率”为 50%。这说明回答内容的安全性较好，但状态分类仍有改进空间；该项已进入人工复核。

## 可靠性发现

当前严格 schema 校验能显式暴露坏输出：Code Review 有 3/36 次不可用，Emotion 与 Navigation 各有 1/36 次降级。旧版表面可用率更高，但会把部分 JSON 解析失败吞掉并返回默认对象，不能直接等同于真实质量更高。建议后续增加 JSON 修复/重试，再以相同数据集回归。

依赖安全审计在两版同一时点均为 140 个报告项（28 low、73 moderate、33 high、6 critical），没有改善，也没有因本次改造新增差异。这是独立的后续治理项。

## 人工盲评结果

12 组 Agent A/B 输出在隐藏版本信息并随机交换 Candidate 1/2 后完成评分：

| 人工指标（1–5）              |  基线 | 当前版 |              变化 |
| ---------------------------- | ----: | -----: | ----------------: |
| Code Review 正确性           | 4.500 |  4.583 |            +0.083 |
| 情绪支持正确性               | 4.167 |  4.750 |            +0.583 |
| 导航相关性                   | 4.000 |  4.583 |            +0.583 |
| 每例无依据断言数（越低越好） | 0.583 |  0.833 |    +0.250（退步） |
| 总体胜出样本                 |  4/12 |   8/12 | 当前版胜率 66.67% |

当前版在情绪支持、学习导航和总体偏好上提升明显，Code Review 正确性小幅提升；但当时的无依据断言数增加，因此触发了后续证据门禁治理。样本量为 12，结果适合用于版本回归和方向判断，不应直接外推为所有学生的真实修复率。

6 个 RAG 样本的人工评分为：答案正确性 4.833/5、证据支持度 4.667/5、无证据问题正确拒答率 100%、每例无依据断言 0.333。人工判断确认提示注入场景的回答内容确实正确拒绝了编造；此前 50% 的自动拒答率主要来自 `grounded` 状态标记与回答语义不一致。

## 证据门禁修复后盲评

为验证上述退步是否得到修复，使用同一批 12 个场景，将修复前 `D-final` 与加入证据绑定、输出校验和自动纠错后的 `benefit-grounding-final` 再次随机换位盲评：

| 人工指标（1–5）              | 修复前 | 修复后 |           变化 |
| ---------------------------- | -----: | -----: | -------------: |
| Code Review 正确性           |  4.083 |  4.833 |         +0.750 |
| 情绪支持正确性               |  4.500 |  5.000 |         +0.500 |
| 导航相关性                   |  3.833 |  4.917 |         +1.084 |
| 每例无依据断言数（越低越好） |  1.333 |  0.167 |        -87.47% |
| 总体胜出样本                 |   0/12 |  12/12 | 修复后全部胜出 |

这说明本轮证据门禁不仅降低了幻觉，也没有以牺牲三个 Agent 的人工质量评分为代价。修复前数值与上表上一轮的 0.833 不同，是因为两者来自不同轮次的人工评分；为避免评审尺度漂移，修复收益只比较本轮同一评审者、同一数据、同一盲评文件中的成对结果。该结果仍是小样本离线评测，不能替代真实学生修复率。
